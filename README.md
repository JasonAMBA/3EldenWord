# 🗡️ 3EldenWord - The boss challenge

Un mini jeu web sur le thème du célèbre jeu Elden Ring où l'utilisateur doit deviner le boss à partir de trois images.

🔗 [Voir le site en ligne](https://3-elden-word.vercel.app/)

## ✨ Fonctionnalités

- Inscription, connexion et déconnexion
- Authentification avec access token et refresh token (JWT)
- Modification et suppression du compte
- Sélection d'une région parmi Necrolimbe, Liurnia et Caelid
- Progression débloquée par niveaux au sein de chaque région
- Barre de progression par région
- 5 tentatives maximum par boss — en cas d'échec, la progression est réinitialisée
- Thème visuel dynamique adapté à chaque région
